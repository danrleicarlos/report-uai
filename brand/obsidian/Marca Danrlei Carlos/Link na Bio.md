# Link na Bio

Página de link na bio para o widget HTML do Elementor Pro. Arquivo no repositório `report-uai`: `elementor/link-na-bio.html`.

## Estrutura

1. Hero: “Danrlei Carlos.”, slogan, `Rule`, foto P&B com disco vermelho.
2. “Escolha seu café.”: cinco `LinkCard` (Uai Sô!, artigo IA output × outcome, acessos no site com IA, método 5R, WhatsApp), todos com UTM `utm_source=instagram&utm_medium=bio&utm_campaign=link_na_bio`.
3. Faixa `Tape` + cartaz provocativo com fita e lightbox.
4. Quem sou eu: `StatBlock` R$ 150.000+/mês e fatos numerados.
5. Post do Instagram incorporado.
6. CTA final em `surface-ink` + botão flutuante do WhatsApp.

## Regras do Elementor

- Todo CSS prefixado por `.dc-bio`; conteúdo em HTML estático; script só como melhoria.
- Nada depende de JavaScript para aparecer (guarda `.elementor-invisible:has(.dc-bio)`).
- Para editar um link: procure o comentário `BOTAO 01` a `BOTAO 05` no arquivo.
