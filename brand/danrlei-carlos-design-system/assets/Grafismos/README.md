# Grafismos

Rabiscos da marca em SVG, para usar fora do React (Canva, Figma, PowerPoint). No código, prefira o componente `Scribble`.

- `coroa.svg` — coroa com escorridos, sobre foto ou estátua. Tinta `#111111` (ink, tema Papel).
- `x-vermelho.svg` — X de negação, sobre o que está errado. Tinta `#b8121b` (red).
- `contagem.svg` — tracinhos de contagem, detalhe de canto. Tinta `#111111`.
- `seta-curva.svg` — seta à mão apontando o próximo bloco (“os links”). Tinta `#b8121b`.
- `risco.svg` — risco duplo sobre palavra negada (“sem achismo”). Tinta `#b8121b`.
- `respingo.svg` — respingo de tinta, atrás de blocos. Tinta `#111111`.
- `xicara.svg` — xícara com vapor, para CTA de café. Tinta `#111111`.
- `divisor.svg` — divisor da marca (cinza `#b9b6b0` · vermelho `#b8121b` · cinza), 120×4.

Todos são de uma tinta fixa (não herdam cor). Para fundo escuro, troque `#111111` por `#efede8` no arquivo.
