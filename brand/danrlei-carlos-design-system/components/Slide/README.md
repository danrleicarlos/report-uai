# Slide

Slide 16:9 em tamanho real (1920×1080).

- `variant`: `title` (capa com foto), `section` (abertura de bloco com número gigante vermelho), `content` (lista numerada em duas colunas, `items`), `data` (até 3 números, `stats: [{value, label}]`), `statement` (fundo preto, frase de respiro).
- Props comuns: `kicker`, `title`, `accent`, `body`, `image`, `number`, `page`.
- Um vermelho por slide; `statement` a cada 4–6 slides.
