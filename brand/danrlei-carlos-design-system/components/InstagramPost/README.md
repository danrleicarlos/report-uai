# InstagramPost

Lâmina de Instagram em tamanho real (1080×1350; `format="story"` para 1080×1920).

- `variant`: `cover` (capa com foto P&B, disco vermelho e coroa), `list` (itens numerados), `statement` (fundo preto, frase com palavra riscada), `stat` (número de prova), `cta` (fundo vermelho, chamada final).
- Props: `kicker`, `title` (string ou array de linhas), `accent`, `body`, `items`, `value`/`suffix`, `note` (anotação), `image` (URL da foto P&B), `action`, `page` (“1/7”), `handle`.
- `scale` só reduz a visualização; exporte em 1. Roteiro do carrossel na seção Formatos.
